Nothing here is optional. Work through the four phases in order before Sarus Operation Planner controls a real aircraft, and if an item fails, stop there and find out why before going on. The ticks are remembered by this browser only, so use one device per test.

Keep with the test record

File the telemetry logs (.tlog, found in Documents\Sarus Operation Planner\logs) and the flight controller's .bin log for every flight, together with the parameter backup from step A2. Add a note for anything unexpected, a message or a behaviour, and write down when it happened. A time stamp makes the log far easier to read later.
